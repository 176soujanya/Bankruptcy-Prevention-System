# Bankruptcy-Prevention-System
Machine Learning Project to Predict Company Bankruptcy Using Six Risk Indicators

# Bankruptcy Prevention System

## Project Overview
This project uses Machine Learning to predict whether
a company is likely to face bankruptcy or not.

## Project Objective
To analyse company risk indicators and predict
Bankruptcy or Non-Bankruptcy.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib

## Input Features
1. Industrial Risk
2. Management Risk
3. Financial Flexibility
4. Credibility
5. Competitiveness
6. Operating Risk

## Machine Learning Models
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Classifier
5. K-Nearest Neighbors

## Best Model
Logistic Regression

Mean cross-validation F1 Score: 99.53%

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Model Training
5. Model Evaluation
6. Model Selection
7. Application Deployment

## Application
The application allows users to enter six risk
indicators and get a bankruptcy prediction.
